# 提案：OneVideo 放映页 · 产品宣传示例

- **产品**：OneVideo 自己的放映页（vedio.mangoqwq.com），演示 promo 流水线：真实界面截图 + 同一台设备贯穿全片 + 点击 → 展开 → 结果停留。
- **受众**：第一次拿到链接的朋友，想知道“点开能干什么”。
- **长度**：约 20 秒，16:9，风格 neon-tech，4 段（开场 / 点开 / 章节 / 收尾）。
- **三个时刻**：一页放下所有视频 → 点卡片展开详情 → 按章节跳着看。
- **素材**：全部由 `onevideo capture` 在手机视口截取线上页面，rect 名（player / card / chapters）直接给设备场景点按与展开用，不手填坐标。
- **节奏**：设备场景之间硬切不重复入场；每个展开结果至少停 1 秒（deviceGate）；点按落在拍点上。
