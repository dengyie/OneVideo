# 提案：SpaceX 上市 · 动效示例

- **角度**：同一份 SpaceX IPO 研究，用实拍和无限画布讲成三段，演示动效引擎的完整用法；数据版见 `examples/spacex-ipo`。
- **受众**：关注科技与资本市场的中文观众，无需金融背景。
- **长度**：约 36 秒，16:9，风格 midnight-data，3 章节（开场 / 上市 / 收入结构）。
- **结构**：钩子（实拍变速 + 标题压在主体后 + 每句一个关键词）→ 发行数字（画布：卡片分层入场、逐位翻牌、镜头连续飞行）→ 收入结构（实拍 + 关键词避让主体 + 对比底）。
- **动效**：镜头轨 `shots`、`through` / `whip` 转场、`music.offset: "auto"` 让切点落在重拍、动态字幕 `kinetic`、`sfx.motion: "auto"`。
- **数据纪律**：所有数字来自 plan/research.json。
