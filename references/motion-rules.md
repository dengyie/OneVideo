# 动效规则

动效是为了让信息按旁白的顺序出现，不是为了装饰。

## 时间

- **跟着声音走**：每个新元素在旁白念到它的那一刻出现。用 `cues` 绑定短语，例如 `"y2026": "排在第一"`；需要提前一点就用 `{ "phrase": "36年后", "offset": -0.4 }`。
- **进场 0.4–0.7s**，用 easeOut；**退场更快**。模板的 `progress(t, at, 0.6)` 是默认节奏，风格的 `motion.pace`（slow / medium / fast = 1.35 / 1 / 0.7）统一缩放它。
- **转场**：场景间默认淡入淡出加一个 whoosh 音效。连续 3 个以上同样的转场会显得机械，在章节处换成 `wipe` 或 `zoom`。
- **停留**：最后一个元素出现后至少停 1.5s 再切走（`hold` 或靠旁白尾音）。

## 运动

- **一次只动一类东西**：柱子在长的时候，标签和标题不要同时飞。
- **数字滚动**：stat-cards 的 `from` → `value` 计数动画，时长不超过 1.2s，最后 20% 放慢。
- **镜头**：media 场景用缓慢推拉（`motion: in/out`）或平移（`left/right/up`），整个场景只走 3–6% 的幅度。
- **背景**：glow 光斑持续缓慢漂移，网格和星空背景缓慢平移。即使前景静止，画面也不会被 QC 判成冻结。
- **排名交换**：bar-race 的交叉期柱子会重叠，所以交换要短（≤1.6s），之后停住。

## 版面

- 布局单位 `u` = 短边 / 1080，所有尺寸都用 `u` 写，同一份 storyboard 可以输出 16:9 / 9:16 / 1:1。
- 字幕带固定在底部，图表区域按“舞台高度 − 标题 − 单位行”计算，永远不压字幕。
- 一屏的文字：标题 ≤16 字，卡片标签 ≤8 字，图表系列名 ≤6 字。
- 颜色：主色 accent 标重点，其余用 palette；涨用 positive、跌用 negative，不要反着用。

## 反模式

- 所有元素同时淡入。
- 弹跳、旋转、3D 翻转之类与内容无关的动效。
- 静止的 bullets 页超过 6 秒。
- 动画在旁白念到之前就播完了，或者在念完很久之后才出现。
