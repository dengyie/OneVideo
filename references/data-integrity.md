# 数据可信度

数据视频的可信度来自一条可追溯的链：**旁白数字 → script.claims → research.facts → source**。门控会强制检查其中能机械检查的部分。

## research.json 规则

- 每个 fact 有 `id`、`claim`（可直接念的中文表述）、`value`、`unit`、`confidence`、`source`。
- `source` 至少要有 `title`，最好有 `publisher`、`date` 和 `url`。没有链接的来源（新闻稿、付费终端）也要写清楚出处，会照常出现在片尾和简介里。
- `confidence`：`confirmed`（一手或交易所/公司公告）、`reported`（权威媒体报道）、`estimate`（二手综述或推算）。`estimate` 在旁白里要说“约”“据估算”。
- `asOf`：整份调研的截止日期。市值、排名这类会变的数字必须带日期。
- 表格类数据（历年排行）的来源放在顶层 `sources`，它们会进入片尾和简介，但不对应单个 fact。
- `openQuestions`：口径冲突、没核到原文的地方写在这里，审稿时一眼可见。

## 门控做了什么

- **numbers**：旁白里每个带单位的数字，必须在某个 fact 的 claim/value/quote 中出现，或在 `allowNumbers` 中。个位数视为结构词跳过。
- **claims**：script 里 `claims` 引用的 fact id 必须存在。
- **source**：没有来源的 fact 直接报错。

门控只能做字面检查，下面这些要靠人：

## 人工核对清单

1. **口径一致**：同一个指标是否来自同一口径（收盘/盘中、发行价估值/首日市值、集团/分部）。
2. **时间一致**：图表里不同时期的数据，计价日分别是什么？写进图表 header 的 subtitle。
3. **单位换算**：亿/万亿、美元/人民币、名义/实际。换算后的数四舍五入到 3 位有效数字。
4. **二手来源**：转载链接（如 taz.de 转载 Business Week）注明“转载”，能找到一手的优先一手。
5. **排序**：bar-race、bar-compare 只放同一来源同一口径的排名；缺数据的期用 `null`，不要补猜。
6. **图表不撒谎**：柱状图从 0 开始；折线图如果截断 y 轴，要在旁白或标注里说明。

## 冲突时怎么办

- 两个来源数字不同：选更一手、更新的那个，把另一个写进 `openQuestions`；旁白用“约”。
- 找不到原文：`confidence: "estimate"`，旁白说“据多家媒体转述”。
- 不能核实的数字不要上屏。宁可少一个数，也不要放一个错的数。
